# Welcome

Welcome to your Markdown Wiki!

## Features

- Create notes using #markdown syntax
- Link notes using [[wiki-links]] 
- Tag your notes with #tags
- Full-text search support
- Backlinks automatically tracked

## Getting Started

1. Create a new note using POST /api/notes
2. Add content with [[links]] and #tags
3. Use the search API to find notes
4. View backlinks to see connected notes
