# Getting Started

Welcome to your **Markdown Wiki**!

## Features

- **[[wiki-links]]**: Link to other notes using double brackets
- **#tagging**: Add tags with #hashtags
- **Full-text search**: Find notes instantly
- **Dark theme**: Easy on the eyes

## Quick Tips

1. Press `Ctrl+N` to create a new note
2. Press `Ctrl+S` to save
3. Press `Escape` to cancel editing
